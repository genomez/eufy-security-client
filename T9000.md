# T9000 (HomeBase Professional S1) — client fork

This branch (`T9000-testing` / `master`) adds support for the **Eufy HomeBase Professional S1 (T9000)** on top of upstream `eufy-security-client` 4.x.

## Home Assistant setup

The client alone is not enough. Use the full stack documented here:

**→ [genomez/hassio-eufy-security-ws — T9000-SETUP.md](https://github.com/genomez/hassio-eufy-security-ws/blob/master/T9000-SETUP.md)**

## What this fork adds

| Area | Summary |
|------|---------|
| Station type | `HOMEBASE_PROFESSIONAL_S1` (device type 27) |
| eufy_mega | v6 login + FCM re-registration after mega session |
| Motion / thumbnails | P2P station push cmds **1317/1318** (not HB3 FCM cmd 2037) |
| Person names | Maps `nick_name` → `person_name` on P2P push |

## Branch

- **`T9000-testing`** — branch the HA add-on builds from
- **`master`** — same tip as `T9000-testing` (stable default)
